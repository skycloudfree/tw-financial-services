# DCF 模型建構工具

## Overview

此技能依照投資銀行標準，建立機構級品質的 DCF 模型進行股權估值。每次分析產出詳細的 Excel 模型（含敏感性分析表於 DCF 工作表底部）。

## 資料來源（台灣市場）

使用 TWSEMCPServer MCP 工具，從以下來源取得資料：

- `get_company_profile`：公司基本資料（股票代號、產業別、實收資本額）
- `get_company_balance_sheet`：資產負債表
- `get_company_income_statement`：綜合損益表
- `get_company_monthly_revenue`：每月營收
- `get_stock_daily_trading`：日成交資訊（股價、成交量）
- `get_company_dividend`：股利分派資料
- `get_company_profitability_analysis`：營益分析
- `get_stock_valuation_ratios`：本益比/殖利率/股價淨值比
- `get_market_historical_index`：歷史指數（用於計算 Beta）

**重要：** 台灣財務報表格式依公司產業別自動切換（一般業、金融業、證券期貨業、金控業、保險業、異業）。

## 關鍵約束 — 建構前請詳讀

以下約束適用於所有 DCF 模型建構。開始前請複習：

**環境：Office JS vs Python/openpyxl：**
- **如在 Excel 內執行（Office 加載項 / Office JS 環境）：** 直接使用 Office JS — 不要用 Python/openpyxl。透過 `range.formulas = [["=D19*(1+$B$8)"]]` 寫入公式。Excel 自動計算。使用 `range.format.*` 設定樣式。
- **如產生獨立 .xlsx 檔案（無即時 Excel 工作階段）：** 使用 Python/openpyxl，交付前執行 `recalc.py`。
- 其他原則（公式字串、儲存格註解、區段檢查點、敏感性迴圈）兩者皆適用。

**Office JS 合併儲存格陷阱：** 不要先 `.merge()` 再對合併範圍設 `.values`。應先將值寫入左上角儲存格，再 merge + 格式化完整範圍。

**公式優於手動數字（不可協商）：**
- 每個預測、利潤率、折現因子、PV 和敏感性儲存格必須是即時 Excel 公式
- 唯一允許的手動數字是：(1) 原始歷史輸入，(2) 假設驅動值（成長率、WACC 輸入），(3) 當前市場數據（股價、負債餘額）
- 如果發現自己在 Python 中計算後寫入結果 — 立刻停止！模型必須隨用戶更改假設而自動彈性調整

**與用戶逐步驗證（不要一次建完）：**
- 資料擷取後 → 展示原始輸入區塊（營收、利潤率、股數、淨負債）並確認再預測
- 營收預測後 → 展示預測營收與成長率，確認再建成本結構
- FCF 建構後 → 展示完整 FCF 時程表，確認邏輯後計算 WACC
- WACC 後 → 展示計算與輸入，確認後折現
- 終值 + PV 後 → 展示權益橋接（EV → 權益價值 → 每股價值），確認後做敏感性分析

**敏感性分析表：**
- **使用奇數行與奇數列**（標準：5×5，有時 7×7）— 確保有真正的中心儲存格
- **中心儲存格 = 基準情境。** 建構軸值使中間列標題和中間欄標題恰好等於模型的實際假設。中心儲存格的輸出必須等於模型實際的隱含股價 — 這是表正確建構的合理性檢查。
- **高亮中心儲存格** 使用中藍色填充（`#BDD7EE`）+ 粗體
- 填充所有儲存格（典型 3 表 × 25 儲存格 = 75 個）使用完整 DCF 重新計算公式
- 無佔位文字、無線性近似、無需手動步驟

**儲存格註解：**
- 在每個手動數字建立時立即添加註解
- 格式：「來源：[系統/文件]，[日期]，[參照處]，[URL]」
- 每個藍色輸入在移至下一區段前必須有註解
- 不要推到最後或寫「TODO: 補來源」

**模型佈局規劃：**
- 在寫入任何公式前，先定義所有區段列位置
- 先寫所有標題與標籤
- 再寫所有區段分隔線與空行
- 然後使用鎖定的列位置寫入公式
- 建立後立即測試公式

**公式重新計算：**
- 交付前執行 `python recalc.py model.xlsx 30`
- 修正所有錯誤直到狀態為 "success"
- 零公式錯誤（#REF!、#DIV/0!、#VALUE! 等）

**情境區塊：**
- 為悲觀/基準/樂觀建立獨立區塊
- 在每個區塊內將假設水平展示於各預測年度
- 使用 IF 公式：`=IF($B$6=1,[悲觀儲存格],IF($B$6=2,[基準儲存格],[樂觀儲存格]))`
- 建議使用 INDEX 公式建立集中欄位（見下方正確模式）

## DCF 流程工作流

### 步驟 1：資料擷取與驗證

從 TWSEMCPServer 與公開資訊觀測站擷取資料。

**資料來源優先順序：**
1. **TWSEMCPServer** — 台灣證交所官方資料（即時股價、財務報表、三大法人買賣超）
2. **公開資訊觀測站 (MOPS)** — 財務報表、每月營收、股利政策
3. **用戶提供資料** — 歷史財務數據、共識預估
4. **網路搜尋/擷取** — 當期股價、Beta、債券殖利率等

**驗證檢查清單：**
- 驗證淨負債 vs 淨現金（對估值至關重要）
- 確認流通在外股數（檢查近期的庫藏股/增資）
- 驗證歷史利潤率與商業模式一致
- 交叉檢查營收成長率與產業基準
- 驗證稅率合理（台灣營所稅率 17%，但財報有效稅率通常 15-25%）

### 步驟 2：歷史分析（3-5 年）

分析與記錄：
- **營收成長趨勢**：計算 CAGR、辨識驅動因素
- **利潤率變遷**：追蹤毛利率、營業利益率、FCF 利潤率
- **資本強度**：折舊與資本支出佔營收比
- **營運資金效率**：營運資金變動佔營收成長比
- **報酬指標**：ROIC、ROE 趨勢

建立摘要表：
```
歷史指標 (LTM)：
營收：XXX 百萬元
營收成長率：X% CAGR
毛利率：X%
營業利益率：X%
折舊佔營收比：X%
資本支出佔營收比：X%
FCF 利潤率：X%
```

### 步驟 3：建立營收預測

**方法論：**
1. 從最新實際營收開始（LTM 或最近會計年度）
2. 對每個預測年度應用成長率
3. 同時顯示金額與成長率百分比

**成長率框架：**
- 第 1-2 年：較高成長反映近期能見度
- 第 3-4 年：逐步趨向產業平均
- 第 5 年後：接近永續成長率

**台灣市場特有考量：**
- 電子業營收受季節性影響顯著（下半年旺季效應）
- 月營收公告（每月 10 日前）是追蹤營收趨勢的關鍵數據
- 台股企業常配發高額現金股利，影響 FCF 計算
- 資本支出週期需考慮台灣半導體/面板業的景氣循環特性

**三情境方式：**
```
悲觀情境：保守成長（如 5-10%）
基準情境：最有可能（如 10-15%）
樂觀情境：樂觀成長（如 15-20%）
```

### 步驟 4：營業費用模型化

**固定/變動成本分析：**

台灣企業營業費用結構常見：
- **銷售費用**：通常營收的 5-20%（電子代工較低、品牌/消費性較高）
- **管理費用**：通常營收的 3-10%
- **研發費用**：半導體/IC 設計 15-30%、製造業 2-5%、金融業極低

**關鍵原則：**
- 所有百分比以營收為基礎，非毛利
- 模型化營運槓桿：% 應隨營收規模下降
- 維持銷售、管理、研發等獨立項目

**利潤率擴張框架：**
```
當前狀態 → 第 5 年目標
毛利率：X% → Y%
營業利益率：X% → Y%
```

### 步驟 5：自由現金流計算

**依序建構 FCF：**

```
營業利益
(-) 稅費（營業利益 × 稅率）
= NOPAT（稅後淨營業利潤）
(+) 折舊攤銷（非現金費用，佔營收比）
(-) 資本支出（佔營收比，通常 3-8%）
(-) 營運資金變動
= 無槓桿自由現金流
```

**營運資金模型化：**
- 按營收變動百分比計算
- 典型範圍：營收變動的 -2% 至 +2%
- 負數 = 資金來源（營運資金釋放）
- 正數 = 資金使用（營運資金積壓）

### 步驟 6：資金成本 (WACC) 計算

**台灣市場 CAPM 方法論：**

```
權益資金成本 = 無風險利率 + Beta × 權益風險溢酬

其中：
- 無風險利率 = 當前台灣 10 年期中央政府公債殖利率（約 1.2-1.8%）
- Beta = 5 年月報酬相對於台灣加權指數
- 權益風險溢酬 = 5.0-6.5%（台灣市場標準，略高於已開發市場）
```

**台灣市場 WACC 參考值：**
- 大型權值股（台積電等）：6-8%
- 中型成長股：8-11%
- 高成長/高風險：11-14%

**負債資金成本計算：**

```
稅後負債資金成本 = 稅前負債資金成本 × (1 - 稅率)

從以下取得稅前負債資金成本：
- 公司信用評等（台灣：中華信評、惠譽台灣）
- 公司債券殖利率
- 利息費用 / 總負債
```

**資本結構權重：**

```
權益市值 = 當前股價 × 流通在外股數
淨負債 = 總負債 - 現金及約當現金
企業價值 = 市值 + 淨負債

權益權重 = 市值 / 企業價值
負債權重 = 淨負債 / 企業價值

WACC = (權益資金成本 × 權益權重) + (稅後負債資金成本 × 負債權重)
```

**特殊情況：**
- **淨現金位置**：若現金 > 負債，淨負債為負值（台灣許多電子業公司為淨現金）
- **無負債**：WACC = 權益資金成本

**台灣市場特有 WACC 考量：**
- 台股高殖利率特性：投資人要求較高股利報酬，影響權益資金成本
- 外資持股比率高的公司（如台積電 70%+），其權益資金成本接近國際標準
- 台灣央行利率政策對公債殖利率的影響
- 中小型股流動性折價

### 步驟 7：折現率應用（5-10 年預測）

**年中慣例：**
- 假設現金流於年中發生
- 折現期間：0.5、1.5、2.5、3.5、4.5
- 折現因子 = 1 / (1 + WACC)^期間

**現值計算：**
```
對每個預測年度：
FCF 現值 = 無槓桿 FCF × 折現因子
```

**預測期間選擇：**
- **5 年**：標準分析
- **7-10 年**：高成長公司（如 IC 設計、生技）
- **3 年**：成熟穩定企業

### 步驟 8：終值計算

**永續成長法（首選）：**

```
終期 FCF = 最後年度 FCF × (1 + 永續成長率)
終值 = 終期 FCF / (WACC - 永續成長率)

關鍵限制：永續成長率 < WACC（否則價值無限大）
```

**永續成長率選擇（台灣市場）：**
- 保守：1.5-2.0%（台灣長期 GDP 成長率 ~2-3%）
- 適中：2.0-3.0%
- 積極：3.0-4.0%（僅市場領導者）

**不可超過**：無風險利率或長期 GDP 成長率

**退出倍數法（替代）：**
```
終值 = 最後年度 EBITDA × 退出倍數

退出倍數來自：
- 同業可比交易倍數
- 先例交易倍數
- 典型範圍：6-15 倍 EBITDA（依產業而異）
```

**終值現值：**
```
終值現值 = 終值 / (1 + WACC)^最終期間
```

**終值合理性檢查：**
- 應佔企業價值的 50-70%
- 若 >75%，模型可能過度依賴終值假設
- 若 <40%，檢查終值假設是否過於保守

### 步驟 9：企業價值至股權價值橋接

**估值摘要結構：**

```
(+) 預測 FCF 現值合計 = XXX 百萬元
(+) 終值現值 = YYY 百萬元
= 企業價值 = ZZZ 百萬元

(-) 淨負債 [或 + 淨現金若為負數] = AAA 百萬元
= 股權價值 = BBB 百萬元

÷ 流通在外股數（百萬股）= CCC
= 每股隱含價值 = XX.XX 元

當前股價 = YY.YY 元
隱含報酬率 = (隱含價值 / 當前股價) - 1 = XX%
```

**關鍵調整（台灣市場特有）：**
- **淨負債 = 總負債 - 現金及約當現金**
- **使用加權平均流通在外股數**（年報揭露）
- **庫藏股調整**：若公司實施庫藏股，需調整股數
- **特別股**：台灣有些公司有特別股，需從權益價值中扣除
- **少數股權**：若合併報表有少數股權需調整
- **員工分紅費用化**：台灣上市櫃公司需認列員工酬勞費用

**估值輸出格式：**
```
估值組成項目,金額（百萬元）
明確預測 FCF 現值,X.X
終值現值,Y.Y
企業價值,Z.Z
(-) 淨負債,A.A
股權價值,B.B
,,
流通在外股數（百萬股）,C.C
每股隱含價值,XX.XX 元
當前股價,YY.YY 元
隱含上漲/(下跌)空間,+XX%
```

### 步驟 10：敏感性分析

在 DCF 工作表底部建構**三個敏感性分析表**，顯示估值如何隨不同假設變化：

1. **WACC vs 永續成長率** — 顯示折現率與永續成長對企業價值的影響
2. **營收成長率 vs 營業利益率** — 顯示營收成長與營運槓桿的影響
3. **Beta vs 無風險利率** — 顯示權益資金成本成分的敏感性

**實作方式**：這些是簡單的二維網格（非 Excel 的「資料表」功能），每個儲存格包含完整 DCF 重新計算公式。詳見關鍵約束區段。

### 正確營收預測模式

**步驟 1 — FY1 成長率集中欄：**
`=INDEX([悲觀 FY1 成長]:[樂觀 FY1 成長], 1, $B$6)`

**步驟 2 — 營收預測參照集中欄：**
`營收第 1 年：=D29*(1+$E$10)`

### 正確 FCF 公式模式

**使用集中欄與 INDEX 公式：**

```
項目,公式,參照
折舊,=E29*$E$21, $E$21 = D&A % 集中欄
資本支出,=E29*$E$22, $E$22 = CapEx % 集中欄
營運資金變動,=(E29-D29)*$E$23, $E$23 = NWC % 集中欄
無槓桿 FCF,=E57+E58-E60-E62, E57=NOPAT E58=D&A E60=CapEx E62=ΔNWC
```

此區段包含建構 DCF 模型時應避免的所有錯誤模式。

### 錯誤：簡化敏感性分析近似或佔位文字

**不要使用線性近似與佔位文字。** 每個儲存格必須是完整 DCF 重新計算公式。

### 錯誤：缺少儲存格註解

**不要這樣做：**
- 建立所有手動輸入但無註解
- 認為「之後再補」
- 寫「TODO: 補來源」

**正確做法：** 在每個手動數字建立時立即添加註解。

### 錯誤：公式列參照偏移

**症狀：**
FCF 區段參照錯誤的假設列。

**原因：**
1. 先寫公式
2. 然後插入標題列
3. 所有列參照偏移 → #REF! 錯誤

**正確做法：** 先鎖定列佈局，再寫公式。

### 錯誤：各情境假設使用單一列

**不要這樣：**
```
假設,悲觀,基準,樂觀
營收成長率 FY1,10%,13%,16%
```

這種垂直佈局難以看到各情境內跨年度的假設演變。

**正確做法：**
- 為每個情境建立獨立區塊
- 在每個區塊內將假設水平展示於各預測年度

### 錯誤：無框線

**正確做法：** 在所有主要區段添加專業框線。

### 錯誤：無字型顏色區別

**正確做法：** 藍色文字 = 手動輸入、黑色文字 = 公式、綠色文字 = 跨工作表連結。

### 前 5 大錯誤摘要

1. **公式列參照偏移** → 在寫公式前先定義所有列位置
2. **缺少儲存格註解** → 在建立儲存格時立即添加，非最後
3. **簡化敏感性分析表** → 所有儲存格填入完整 DCF 重新計算公式
4. **情境區塊參照錯誤** → 確保公式從正確區塊取值
5. **無框線** → 添加專業區段框線

### WACC 計算錯誤
- 資本結構中混用帳面值與市值
- 錯誤的稅率應用於負債資金成本
- 無風險利率使用錯誤（必須使用當前台灣 10 年期公債殖利率）
- 未調整淨負債 vs 淨現金位置

### 終值錯誤
- 終值 > 企業價值的 80%（過度依賴）
- 終值利潤率與穩定狀態假設不一致
- 終值折現期間錯誤

### 現金流預測錯誤
- 營業費用基於毛利而非營收
- 折舊/資本支出百分比與商業模式不一致
- 營運資金變動計算不正確
- 各年度稅率不一致

**台灣市場 WACC 公式：**
```

企業價值 = 市值 + 淨負債

負債權重 = 淨負債 / EV
```

## 案例選擇器實作

### 三案例框架

**悲觀情境：**
- 保守營收成長（歷史範圍低端）
- 利潤率壓縮或無擴張
- 較高 WACC（風險溢價增加）
- 較低永續成長率
- 較高資本支出假設
- 適用於：總體經濟放緩、產業逆風

**基準情境：**
- 共識或管理層指引營收成長
- 基於營運槓桿的適度利潤率擴張
- 當前市場隱含 WACC
- GDP 對齊的永續成長（2.0-2.5%）
- 適用於：正常營運環境

**樂觀情境：**
- 樂觀營收成長（預測高端）
- 顯著利潤率擴張
- 較低 WACC（風險溢價下降）
- 較高永續成長（3.0-4.0%）
- 適用於：新產品線、市占率擴張
