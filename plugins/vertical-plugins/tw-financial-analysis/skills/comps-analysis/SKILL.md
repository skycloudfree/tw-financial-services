# 可比公司分析（Comparable Company Analysis）

## ⚠️ 關鍵：資料來源優先順序（務必先讀）

**一律遵循此資料來源階層：**

1. **優先：使用 TWSEMCPServer MCP 工具** — 透過 TWSE OpenAPI 取得財務與交易資料
   - `get_company_profile` 取得基本資料
   - `get_company_balance_sheet` 取得資產負債表
   - `get_company_income_statement` 取得綜合損益表
   - `get_stock_valuation_ratios` 取得本益比/殖利率/股價淨值比
   - `get_stock_daily_trading` 取得日成交資訊
   - `get_company_monthly_revenue` 取得每月營收
2. **次選：使用公開資訊觀測站（MOPS）** — 官方財務報表、重大訊息
3. **最後手段：網路搜尋** — 僅在 MCP 與 MOPS 均無法取得時使用
4. **一律避免將網路搜尋作為主要資料來源** — 缺乏準確性、審計軌跡與可靠性

**為何重要：** TWSEMCPServer 提供台灣證交所官方驗證的即時資料。網路搜尋結果可能過時、不準確或不可靠。

---

## Overview

此技能教導 Claude 建立機構級可比公司分析，結合營運指標、估值倍數與統計基準。產出為結構化 Excel/試算表格式，透過同業比較輔助投資決策。

**參考素材使用原則：**

範例檔案位於 `examples/comps_example.xlsx`。使用時請注意：

**可參考的：**
- 了解結構層次（區塊如何串聯）
- 掌握要求的嚴謹程度（統計深度、文件標準）
- 學習原則（清楚標題、透明公式、審計軌跡）

**不可複製的：**
- 完全照搬格式或指標
- 不考慮情境的版面複製
- 忽略受眾的視覺風格套用

**開始前必問：**
1. **您有偏好的格式或要我沿用模板風格？**
2. **受眾是誰？**（投資委員會、董事會簡報、快速參考、詳細備忘錄）
3. **關鍵問題是什麼？**（估值、成長分析、競爭定位、效率分析）
4. **評估情境為何？**（併購評估、投資決策、產業基準、績效檢討）

**根據具體情況調整：**
- **產業情境**：大型權值股與中小型股的指標不同
- **產業特定需求**：提前加入相關指標（如半導體：晶圓產能利用率、先進製程占比）
- **公司熟悉度**：知名公司可減少背景說明，聚焦差異分析
- **決策類型**：併購與投資組合監控的重點不同

**核心原則：** 運用模板原則（清晰結構、統計嚴謹、透明公式），但根據情境調整執行方式。目標是機構級分析品質，而非機構級範本外觀。

## 核心哲學
**「先建立正確的結構，讓數據自己說話。」**

從強制策略思考的標題開始，輸入乾淨數據，建立透明公式，讓統計數據自然呈現。好的可比分析應讓未參與建構的人也能立即解讀。

---

## ⚠️ 關鍵：公式優於手動輸入 + 逐步驗證

**環境 — Office JS vs Python：**
- **如在 Excel 內執行（Office 加載項 / Office JS）：** 直接使用 Office JS（`Excel.run(async (context) => {...})`）。透過 `range.formulas = [["=E7/C7"]]` 寫入公式，不要用 `range.values`。Excel 會自動計算。使用 `range.format.*` 設定顏色/字型。
- **如產生獨立 .xlsx 檔案：** 使用 Python/openpyxl。寫入 `cell.value = "=E7/C7"` 作為公式字串。
- 原則相同 — 只是 API 呼叫方式不同。
- **Office JS 合併儲存格陷阱：** 不要先 `.merge()` 再對合併範圍設 `.values`（會拋出 `InvalidArgument`）。應先將值寫入左上角儲存格，再 merge + 格式化完整範圍。

**公式，不是手動數字：**
- 每個衍生值（比率、倍數、統計）必須是參照輸入儲存格的 Excel 公式 — 絕不能是預先計算的數字
- 使用 Python/openpyxl 時：寫 `cell.value = "=E7/C7"`，不是 `cell.value = 0.687`
- 唯一允許的手動數字是：(1) 原始輸入數據，(2) 假設驅動值（成長率、WACC 輸入），(3) 當前市場數據（股價、淨債務）
- 原因：模型必須在輸入變更時自動更新

**與用戶逐步驗證：**
- 建立結構後 → 先展示標題配置，再填入數據
- 輸入原始數據後 → 展示輸入區塊並確認來源/期間，再建立公式
- 建立營運指標公式後 → 展示計算結果並合理性檢查，再移向估值
- 建立估值倍數後 → 展示倍數並確認合理性，再加入統計
- 不要一次建完整個試算表才呈現 — 及早發現錯誤

## Section 1: 文件結構與設定

### 標題區塊
```
第 1 行：[分析標題] - 可比公司分析
第 2 行：[公司列表] • [公司 1 (股票代號)] • [公司 2 (股票代號)] • [公司 3 (股票代號)]
第 3 行：截至 [期間] | 單位：新台幣百萬元，每股資料與比率除外
```

### 視覺慣例標準（可選 — 用戶偏好與上傳模板優先）

**重要：以下為建議預設值。一律優先採用：**
1. 用戶明確的格式偏好
2. 上傳的模板檔案
3. 公司/團隊風格指南
4. 此預設值（僅在無其他指導時使用）

**建議字型與排版：**
- **字型**：Times New Roman（專業、可讀、業界標準）
- **字級**：數據 11pt，標題 12pt
- **粗體**：區塊標題、公司名稱、統計標籤

**預設配色 — 專業藍/灰調色盤：**
- **保持克制** — 僅使用藍色與灰色。不要引入綠、橙、紅或多種強調色
- **區塊標題**：深藍色背景（`#1F4E79`）+ 白色粗體文字
- **欄位標題**：淺藍色背景（`#D9E1F2`）+ 黑色粗體文字，置中對齊
- **數據列**：白色背景，公式用黑色文字，手動輸入用藍色文字
- **統計列**：淺灰色背景（`#F2F2F2`），黑色文字，靠左對齊標籤
- **這就是全部配色**：深藍 + 淺藍 + 淺灰 + 白。除非用戶模板另有規定

**建議格式慣例：**
- **小數精度**：
  - 百分比：1 位小數（12.3%）
  - 倍數：1 位小數（13.5 倍）
  - 金額：無小數，千位分隔符（69,632）
- **框線**：無框線（簡潔、乾淨）
- **對齊**：所有指標置中對齊
- **儲存格尺寸**：欄寬一致，列高一致

## Section 2: 營運統計與財務指標

### 核心欄位
1. **公司** - 格式一致的公司名稱
2. **營收** - 規模指標（LTM、季或年）
3. **營收成長率** - 年增率
4. **營業毛利** - 營收減營業成本
5. **毛利率** - 毛利/營收
6. **營業利益** - 本業獲利（台灣財報：營業利益 = 營收 - 營業成本 - 營業費用）
7. **營業利益率** - 營業利益/營收

**注意：台灣財報格式**
- 台灣公司財報依 IFRS 編製
- 金融業、保險業、金控業有特定格式，由 TWSEMCPServer 自動偵測產業別回傳對應報表
- 一般製造業：營業利益 = 營業收入 - 營業成本 - 營業費用
- 電子業常見額外科目：外銷收入、內銷收入

### 可選欄位（依產業/目的選擇）
- **EBITDA** - 稅前息前折舊攤銷前獲利
- **EBITDA 利潤率** - EBITDA/營收
- **自由現金流** - 營業現金流 - 資本支出
- **稅後淨利** - 歸屬於母公司業主淨利
- **每股盈餘 (EPS)** - 稅後淨利/流通在外股數
- **每股淨值 (BVPS)** - 權益/流通在外股數
- **本益比 (P/E)** - 股價/EPS

### 台股特有指標（新增）
- **股價淨值比 (P/B)** - 台灣市場常用估值指標（尤其金融股）
- **現金殖利率** - 現金股利/股價（台灣高殖利率特性顯著）
- **月營收年增率** - 台灣每月 10 日前公告前月營收
- **外資持股比率** - 外資持股/流通在外股數
- **融資餘額 / 融券餘額** - 散戶籌碼指標
- **當沖比率** - 當沖成交量/總成交量（台灣市場特色）

### 公式範例
```excel
// 核心比率
毛利率：=營業毛利/營收
營業利益率：=營業利益/營收
EBITDA 利潤率：=EBITDA/營收

// 台股特定
本益比：=股價/EPS
股價淨值比：=股價/每股淨值
現金殖利率：=現金股利/股價
```

### 統計區塊（公司數據之後）

**關鍵：為所有可比較指標添加統計公式（比率、利潤率、成長率、倍數）**

```
[留一空行作為視覺分隔]
- 最大值：=MAX(B7:B9)
- 第 75 百分位：=QUARTILE(B7:B9,3)
- 中位數：=MEDIAN(B7:B9)
- 第 25 百分位：=QUARTILE(B7:B9,1)
- 最小值：=MIN(B7:B9)
```

**需要統計的欄位（可比較指標）：**
- 營收成長率、毛利率、營業利益率、EPS
- 本益比、股價淨值比、現金殖利率、EV/營收

**不需要統計的欄位（規模指標）：**
- 營收、營業利益、稅後淨利（規模因公司而異）
- 市值、企業價值（不同規模公司不可比）

## Section 3: 估值倍數與投資指標

### 核心估值欄位
1. **公司** - 與營運區塊相同順序
2. **市值** - 當前市場估值（股價 × 流通在外股數）
3. **企業價值 (EV)** - 市值 ± 淨負債/現金
4. **EV/營收** - 市場為每元營收支付多少
5. **EV/EBITDA** - 市場為每元 EBITDA 支付多少
6. **本益比 (P/E)** - 股價相對每股盈餘

### 可選估值指標（依情境選擇）
- **股價淨值比 (P/B)** - 台灣市場重要參考指標
- **現金殖利率** - 現金股利/股價
- **股價營收比 (P/S)** - 市值/營收
- **殖利率** - 總股利/股價

### 台股市場估值參考區間
- **本益比**：
  - 電子股：10-25 倍
  - 金融股：8-15 倍
  - 傳產股：10-20 倍
  - 高成長股：20-40 倍
- **股價淨值比**：
  - 電子股：1.5-5 倍
  - 金融股：0.8-2 倍
  - 景氣循環股：0.5-2 倍
- **現金殖利率**：
  - 一般：3-6%（台灣市場常態偏高）
  - 高殖利率：6-10%
  - 特別股/穩定股：4-7%

### 公式範例
```excel
// 核心倍數
EV/營收：=[企業價值]/[LTM 營收]
EV/EBITDA：=[企業價值]/[LTM EBITDA]
本益比：=[市值]/[稅後淨利]

// 台灣市場特定
股價淨值比：=[股價]/[每股淨值]
現金殖利率：=[每股股利]/[股價]
```

### 跨區塊參照規則
**關鍵：** 估值倍數必須參照營運指標區塊。永遠不要重複輸入相同原始數據。

### 統計區塊
與營運區塊相同結構：最大值、75th、中位數、25th、最小值。

## Section 4: 備註與方法論文件

### 必要項目

**資料來源與品質：**
- 資料來源？（TWSEMCPServer、公開資訊觀測站、公司年報）
- 涵蓋期間？（2025 年第 1 季、經會計師查核）
- 如何驗證？（與公開資訊觀測站交叉比對）

**台灣市場資料來源說明：**
- **TWSEMCPServer**：即時報價、歷史股價、三大法人買賣超、融資融券、本益比/殖利率/股價淨值比
- **公開資訊觀測站 (MOPS)**：財務報表、每月營收、重大訊息、股利分派
- **台灣證交所 (TWSE)**：上市股票交易資訊、盤後統計
- **櫃買中心 (TPEx)**：上櫃股票資料
- **公司法說會資料**：TWSE 法說會申報系統

**關鍵定義：**
- EBITDA 計算方式（營業利益 + 折舊 + 攤銷）
- 自由現金流公式（營業現金流 - 資本支出）
- 期間定義（LTM、CAGR 計算期間）

**台灣市場特有考量：**
- 漲跌幅限制：上市/上櫃股票 ±10%、第一上市（KY 股）±10%
- 注意股/處置股機制（當日漲跌幅限制縮小為 5-10%）
- 暫停交易機制（重大訊息公布前）
- 信用交易（融資融券）限制

**估值方法論：**
- 企業價值如何計算？（市值 + 淨負債）
- 成長率採用？（歷史 CAGR、市場共識預估）
- 調整項目？（一次性項目排除、常態化利潤率）

## Section 5: 選擇正確指標（決策框架）

### 從「我想回答什麼問題？」開始

**「哪家公司被低估？」**
→ 聚焦：本益比、EV/EBITDA、股價淨值比、現金殖利率
→ 跳過：營運細節、成長指標

**「哪家公司最有效率？」**
→ 聚焦：毛利率、營業利益率、資產報酬率
→ 跳過：規模指標、絕對金額

**「哪家公司成長最快？」**
→ 聚焦：營收成長率、月營收年增率、EPS 成長率
→ 跳過：利潤率、槓桿比率

**「哪家現金流最佳？」**
→ 聚焦：自由現金流、FCF 利潤率、資本支出強度
→ 跳過：EBITDA、本益比

### 台灣產業適用指標

**半導體：**
必備：營收成長率、毛利率、營業利益率、本益比
可選：晶圓產能利用率、先進製程占比、研發費用率
跳過：存貨周轉（Fabless 不適用）

**電子代工/EMS：**
必備：營收成長率、營業利益率、資產周轉率
可選：毛利率、存貨周轉天數
跳過：高倍數估值（本益比通常偏低）

**金融保險：**
必備：ROE、逾期放款比率、資本適足率、股價淨值比
可選：淨利差、手續費收入占比
跳過：毛利率、EBITDA（金融業不適用）

**航運：**
必備：營收成長率、營業利益率、本益比、股價淨值比
可選：運價指數、艙位利用率
跳過：以本益比為主的估值（景氣循環需另加注意）

**傳產/製造：**
必備：營收成長率、毛利率、營業利益率、資產周轉率
可選：ROE、負債比
跳過：高成長倍數（傳產多為價值股）

### 「5-10 法則」

**5 個營運指標** — 營收、成長率、2-3 個利潤率/效率指標
**5 個估值指標** — 市值、EV、3 個倍數
**= 10 個欄位** — 足以說故事，不會失焦

超過 15 個指標通常是雜訊。嚴格取捨。

## Section 6: 最佳實務與品質檢查

### 開始之前
1. **定義同業群組** — 公司必須真正可比（相似商業模式、規模、市場）
2. **選擇正確期間** — LTM 平滑季節性；季度顯示趨勢
3. **預先統一單位** — 百萬 vs 億的決策影響一切
4. **規劃資料來源** — 知道每個數字從哪裡來

### 建構過程
1. **先輸入所有原始資料** — 完成藍色文字再寫公式
2. **為所有手動輸入值添加儲存格註解** — 右鍵儲存格 → 插入註解 → 記錄來源或假設
   - 範例：「TWSEMCPServer — 收盤價 2026-06-05」
   - 範例：「公開資訊觀測站 — 2025 年度財報，第 42 頁」
   - 註解應包含來源出處與查詢日期
3. **逐列建構公式** — 測試每個計算後再繼續
4. **使用絕對參照** — `$C$6` 鎖定標題列
5. **格式一致** — 百分比使用百分比格式
6. **設定條件格式** — 自動標示異常值

### 合理性檢查
- **利潤率測試**：毛利率 > 營業利益率 > 稅後淨利率（定義上永遠成立）
- **倍數合理性**：
  - 本益比：一般 10-50 倍（台股常態）
  - 股價淨值比：一般 1-5 倍
  - 現金殖利率：一般 3-8%（台股常態偏高）
- **成長-倍數相關性**：高成長通常意味著高倍數
- **規模-效率關聯**：大公司通常利潤率較高

### 常見錯誤
❌ 市值與企業價值混用
❌ 分母分子使用不同期間（LTM vs 季度）
❌ 公式中使用手動數字而非儲存格參照
❌ 手動輸入值無儲存格註解
❌ 包含過多指標無明確目的
❌ 包含不可比的公司
❌ 使用過時數據未揭露
❌ 百分比的平均值計算方式錯誤（應使用中位數）

## Section 10: 紅旗與警示

### 資料品質問題
🚩 不一致的期間（混合季度與年度）
🚩 數據缺失無說明
🚩 不同來源間差異顯著（>10%）

### 估值警示
🚩 本益比 >50 倍且無高成長支撐
🚩 股價淨值比 <0.5 倍（可能有財務風險）
🚩 殖利率異常偏高（可能為景氣循環高點或股利不穩定）
🚩 注意股/處置股（可能人為炒作）

### 可比性問題
🚩 不同會計年度（造成時間差異）
🚩 混合純粹業務與多角化集團
🚩 商業模式實質差異卻標記為「同業」
🚩 **KY 股（第一上市）vs 本國上市股 — 資訊透明度差異大**

**有疑問時，排除該公司。** 3 個完美的可比勝過 6 個有問題的。

## Section 11: 公式參考指南

### 必備 Excel 公式
```excel
// 統計函數
=AVERAGE(範圍)          // 算術平均
=MEDIAN(範圍)           // 中位數
=QUARTILE(範圍, 1)      // 25 百分位
=QUARTILE(範圍, 3)      // 75 百分位
=MAX(範圍)              // 最大值
=MIN(範圍)              // 最小值
=STDEV.P(範圍)          // 標準差

// 財務計算
=B7/C7                   // 簡單比率
=SUM(B7:B9)/3            // 多家公司平均值
=IF(B7>0, C7/B7, "N/A")  // 條件計算
=IFERROR(C7/D7, 0)       // 處理除零錯誤
```

### 常用比率公式
```excel
毛利率 = 營業毛利 / 營收
營業利益率 = 營業利益 / 營收
EBITDA 利潤率 = EBITDA / 營收
本益比 = 股價 / EPS
股價淨值比 = 股價 / 每股淨值
現金殖利率 = 每股股利 / 股價
FCF 利潤率 = 自由現金流 / 營收
ROE = 稅後淨利 / 股東權益
ROA = 稅後淨利 / 總資產
資產周轉率 = 營收 / 總資產
負債比 = 總負債 / 股東權益
```

## 核心原則摘要

1. **結構驅動洞察** — 正確的標題迫使正確的思考
2. **少即是多** — 10 個重要指標勝過 20 個無用指標
3. **依問題選指標** — 估值分析 ≠ 效率分析
4. **統計顯示型態** — 中位數/四分位數比平均數更有洞察力
5. **透明度勝於複雜度** — 簡單公式人人能理解
6. **可比性是關鍵** — 寧可排除也不要勉強湊數
7. **記錄選擇** — 在備註中說明選擇哪些指標及原因
