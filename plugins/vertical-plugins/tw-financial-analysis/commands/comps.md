# 可比公司分析指令

建立機構級可比公司分析，包含營運指標、估值倍數與統計基準。

## 工作流程

### 步驟 1：收集公司資訊

如提供公司名稱或股票代號則使用。否則詢問：
- 「請問要分析哪家公司？（請提供 4 碼股票代號）」

### 步驟 2：載入可比公司分析 Skill

使用 `skill: "comps-analysis"` 建立分析：

1. **確認分析目的**：
   - 「關鍵問題是什麼？」（估值、效率、成長比較）
   - 「受眾是誰？」（投資委員會、董事會、快速參考）
   - 「有偏好的格式或範本嗎？」

2. **辨識同業組**（4-6 家可比公司）：
   - 相似商業模式
   - 相似市值規模（台股：大型股 500 億+、中型股 50-500 億、小型股 <50 億）
   - 相同產業分類
   - 注意：KY 股與本國股的可比性

3. **收集資料**（優先使用 TWSEMCPServer）：
   - 使用 `get_company_profile` 取得基本資料
   - 使用 `get_company_income_statement` 取得營收/獲利
   - 使用 `get_company_balance_sheet` 取得資產負債
   - 使用 `get_stock_valuation_ratios` 取得本益比/殖利率/股價淨值比
   - 使用 `get_stock_daily_trading` 取得日成交資訊
   - 營運指標：營收、成長率、毛利率、營業利益
   - 估值：市值、企業價值、本益比、股價淨值比、現金殖利率

4. **建立分析**：
   - 營運統計區段 + 統計（Max、75th、中位數、25th、Min）
   - 估值倍數區段 + 統計摘要
   - 備註與方法論文件

### 步驟 3：建立 Excel 輸出

產生 Excel 檔案：
- 標題區塊（分析標題、公司、日期、單位）
- 營運統計與財務指標區段
- 估值倍數區段
- 各指標統計摘要
- 備註區記錄來源與方法論

### 步驟 4：交付輸出

提供：
1. **Excel 檔案** (.xlsx) — 可比公司分析
2. **摘要** 包含：
   - 同業選擇理由
   - 關鍵洞察（誰溢價/折價交易）
   - 中位數倍數參考

## 台灣產業適用指標

| 產業 | 適用指標 |
|------|----------|
| 半導體 | 毛利率、研發費用率、先進製程占比、本益比、EV/EBITDA |
| 電子代工 | 營收規模、營業利益率、資產周轉率、本益比 |
| 金融保險 | ROE、逾期放款率、股價淨值比、現金殖利率 |
| 航運 | 營收成長率、營業利益率、股價淨值比、本益比 |
| 傳產/製造 | 毛利率、負債比、資產周轉率、殖利率 |

## 品質檢查清單

交付前：
- [ ] 4-6 家真正可比公司
- [ ] 期間一致（皆 LTM 或皆 FY）
- [ ] 所有公式參照儲存格（無手動數字）
- [ ] 所有手動輸入有註解含來源
- [ ] 統計含 Max、75th、中位數、25th、Min
- [ ] 備註區記錄來源與方法論
- [ ] 藍色 = 輸入、黑色 = 公式
- [ ] 合理性檢查通過

## 資料來源

使用 TWSEMCPServer 工具：
- `get_company_profile` — 公司基本資料
- `get_company_income_statement` — 綜合損益表
- `get_company_balance_sheet` — 資產負債表
- `get_stock_valuation_ratios` — 本益比/殖利率/淨值比
- `get_stock_daily_trading` — 日成交資訊
- `get_company_monthly_revenue` — 每月營收
