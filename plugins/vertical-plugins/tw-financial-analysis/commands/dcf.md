# DCF 估值指令

建立機構級 DCF 模型，使用可比公司分析輔助估值區間。

## 工作流程

### 步驟 1：收集公司資訊

如提供公司名稱或股票代號則使用。否則詢問：
- 「請問要對哪家公司進行估值？（請提供 4 碼股票代號）」

### 步驟 2：執行可比公司分析

**先載入 comps-analysis skill** 建立交易比較：

使用 `skill: "comps-analysis"` 執行：
1. 找出 4-6 家可比上市櫃公司
2. 取得營運指標（營收、營業利益、利潤率、成長率）
3. 取得估值倍數（本益比、EV/營收、EV/EBITDA、股價淨值比）
4. 計算統計摘要（中位數、25th/75th 百分位）

**從比較中取得的關鍵輸出：**
- 同業中位數本益比 → 交叉檢查 DCF 隱含本益比
- 同業中位數 EV/EBITDA → 終值退出倍數參考
- 同業成長率 → 營收預測基準
- 同業利潤率 → 利潤假設基準

### 步驟 3：建立 DCF 模型

**載入 dcf-model skill** 建構估值：

使用 `skill: "dcf-model"` 執行：
1. 收集歷史財務資料與市場數據
2. 建立營收預測（悲觀/基準/樂觀）
3. 模型化營業費用與 FCF
4. 使用 CAPM 計算 WACC（台灣市場參數）
5. 折現現金流並計算終值
6. 橋接至股權價值與每股隱含價值

**使用比較輔助 DCF 假設：**

| 比較輸出 | DCF 輸入 |
|----------|----------|
| 同業中位數本益比 | 交叉檢查 DCF 隱含本益比 |
| 同業 25th-75th 本益比 | 敏感性分析範圍 |
| 同業中位數成長率 | 營收假設基準 |
| 同業中位數營業利益率 | 終期年度目標利潤率 |
| 同業中位數殖利率 | 股利發放假設 |

### 步驟 4：交叉檢查估值

DCF 完成後，驗證：
1. **DCF 隱含本益比** vs 同業中位數
   - 如 DCF 隱含 25 倍但同業交易 15 倍，調查原因
2. **DCF 隱含股價淨值比** vs 同業中位數
3. **終值佔 EV 比重**（應為 50-70%）
4. **隱含成長率** vs 同業成長率

### 步驟 5：交付輸出

提供：
1. **可比公司分析試算表** (.xlsx)
2. **DCF 模型** (.xlsx) 含：
   - 悲觀/基準/樂觀情境
   - 敏感性分析表（WACC vs 永續成長率等）
   - 估值摘要含隱含上漲/下跌空間
3. **摘要** 說明：
   - 關鍵估值驅動因子
   - 比較如何輔助分析
   - 需關注的風險與敏感性

## 台灣市場 DCF 關鍵參數

| 參數 | 台灣市場適用值 |
|------|---------------|
| 無風險利率 | 台灣 10 年期公債殖利率（約 1.2-1.8%） |
| 權益風險溢酬 | 5.0-6.5% |
| 大型股 WACC | 6-8% |
| 中型成長股 WACC | 8-11% |
| 高風險公司 WACC | 11-14% |
| 營所稅率 | 17%（有效稅率通常 15-25%） |
| 永續成長率 | 1.5-2.5%（台灣 GDP ~2-3%） |

## 輸出摘要範例

```
估值摘要：[公司名稱] ([股票代號])

可比公司分析：
- 同業組：[4-6 家同業]
- 中位數本益比：15.5 倍（區間：12.0 倍 - 20.0 倍）
- 中位數股價淨值比：2.2 倍（區間：1.5 倍 - 3.0 倍）

DCF 估值（基準情境）：
- 每股隱含價值：XX.X 元
- 當前股價：YY.Y 元
- 隱含上漲空間：+XX%

估值交叉檢查：
- DCF 隱含本益比：16.5 倍（vs 同業中位數 15.5 倍）
- DCF 隱含股價淨值比：2.3 倍（vs 同業中位數 2.2 倍）
- 終值佔 EV：62%（在正常範圍內）

關鍵假設：
- 營收 CAGR：X%（vs 同業中位數 X%）
- 終期營業利益率：X%（vs 同業中位數 X%）
- WACC：X.X%
- 永續成長率：X.X%
```

## 資料來源

使用 TWSEMCPServer 工具取得台灣市場數據：
- `get_company_profile` — 公司基本資料
- `get_company_income_statement` — 綜合損益表
- `get_company_balance_sheet` — 資產負債表
- `get_stock_valuation_ratios` — 本益比/殖利率/股價淨值比
- `get_stock_daily_trading` — 日成交資訊（股價）
- `get_company_monthly_revenue` — 月營收趨勢
- `get_company_dividend` — 股利政策
