# 投資想法產生 (Idea Generation)

## 工作流程

### 步驟 1：定義搜尋條件

詢問使用者參數：
- **方向**: 做多、做空或兩者
- **市值**: 大型、中型、小型、微型
- **產業**: 特定產業或跨產業
- **風格**: 價值、成長、優質、特殊情境、事件驅動
- **地區**: 台灣、全球
- **主題**: 特定主題角度（AI、供應鏈移轉、高齡化等）

### 步驟 2：量化篩選

依風格執行篩選：

**價值篩選**
- 本益比低於產業中位數
- EV/EBITDA 低於歷史平均
- 自由現金流收益率 >5%
- 股價淨值比低於 1.5x
- 近 90 天內部人買進
- 殖利率高於市場平均

**成長篩選**
- 營收年增率 >15%
- 獲利年增率 >20%
- 營收加速（成長率遞增）
- 利潤率擴張
- 高投入資本報酬率 (>15%)
- 強淨留存率 (>110% 用於 SaaS)

**優質篩選**
- 營收持續成長（5 年以上）
- 利潤率穩定或擴張
- ROE >15%
- 低負債權益比
- 高自由現金流轉換率
- 內部人持股 >5%

**做空篩選**
- 營收衰退或成長減速
- 利潤率壓縮
- 應收帳款/存貨增加幅度高於營收
- 內部人賣出
- 無合理理由的估值溢價
- 高融券比率且基本面惡化
- 會計紅旗（會計師變更、財報重編）

**特殊情境篩選**
- 近期 IPO / 閉鎖期屆滿
- 近 12 個月分割/分拆
- 正在進行重整的公司
- 積極主義股東介入
- 績效不佳公司管理層變動

### 步驟 3：主題掃描

針對主題想法，研究主題並辨識受益者：

1. 定義論點（如「AI 基礎建設支出加速至 2026 年」）
2. 繪製價值鏈 — 直接 vs. 間接受益者？
3. 辨識純粹 vs. 多元化 exposure
4. 評估哪些標的已「price in」vs. 尚未被市場重視
5. 尋找市場尚未連結到主題的二階受益者

### 步驟 4：想法呈現

對每個通過篩選的想法，呈現：

**[公司名稱] — [做多/做空] — [一句話論點]**

| 指標 | 數值 | vs. 同業 |
|------|------|----------|
| 市值 | | |
| EV/EBITDA (NTM) | | |
| P/E (NTM) | | |
| 營收成長 | | |
| EBITDA 利潤率 | | |
| FCF 收益率 | | |

**論點（3-5 點）：**
- 為何被錯誤定價
- 市場忽略什麼
- 實現價值的催化劑

**關鍵風險：**
- 哪些情況會使論點錯誤

**建議下一步：**
- 建立完整模型？深入盡職調查？專家訪談？

### 步驟 5：產出

- 5-10 個想法的短名單，含一頁摘要
- 篩選條件與方法論記載
- 所有想法的比較表
- 優先順序清單：哪些想法應優先研究

## 重要提醒

- 篩選僅是候選名單，非結論 — 每個篩選結果都需基本面分析
- 最好的想法常在交集處（如：因暫時逆風而低價的優質公司）
- 避免擁擠交易 — 檢查法人持股、融券比率及分析師覆蓋數
- 逆向想法需要催化劑 — 沒有催化劑的 early 等同於 wrong
- 長期追蹤想法命中率 — 哪些篩選方式產生最佳想法？
- 做空想法需更高 conviction — 時機更難掌握且風險不對稱
