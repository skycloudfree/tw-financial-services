# 催化劑日曆 (Catalyst Calendar)

## 工作流程

### 步驟 1：定義涵蓋範圍

- 追蹤公司清單（代號或名稱）
- 產業 / 行業焦點
- 是否納入總經事件？（央行利率決策、經濟數據公佈、法規截止日）
- 時間範圍（未來 2 週、1 個月、季度）

### 步驟 2：收集催化劑

針對每家公司，辨識 upcoming 事件：

**財報與財務事件**
- 季報公告日期與時段（盤後/盤前）
- 股東常/臨時會
- 法人說明會 / 分析師日
- 資本市場日
- 債務到期 / 再融資日期

**公司事件**
- 產品上市或發表
- 主管機關核准 / 法規決議
- 合約續約或到期
- M&A 里程碑（交割日、監管核准）
- 經營團隊異動
- 內部人申報轉讓期間（閉鎖期屆滿）

**產業事件**
- 大型研討會（日期、哪些公司出席）
- 貿易展與博覽會
- 法規意見徵詢期或裁決
- 產業數據發布（月營收、出貨量等）

**總經事件**
- 央行理監事會議（台灣央行日期）
- 就業報告、CPI、GDP 發布
- 主要央行決策（FED、ECB、BOJ 等）
- 影響市場的地緣政治事件

### 步驟 3：日曆檢視

| 日期 | 事件 | 公司/產業 | 類型 | 影響(H/M/L) | 持倉方向 | 備註 |
|------|------|-----------|------|-------------|-----------|------|
| | | | 財報/公司/產業/總經 | | 做多/做空/中性 | |

### 步驟 4：週報預覽

每週產出 forward-looking 摘要：

**本週關鍵事件：**
1. [日]: [公司] Q[X] 季報 — 市場共識 [NT$X EPS]，我們預估 [NT$X]，關注焦點：[指標]
2. [日]: [事件] — 為何對 [股票] 重要
3. [日]: [總經數據發布] — 預期與持倉

**下週預覽：**
- 重要事件提前預告

**持倉啟示：**
- 可能影響特定持倉的事件
- 建議預先布局
- 二元事件前的風險管理

### 步驟 5：產出

- Excel 日曆（可排序欄位）
- 週報預覽 (markdown)
- 可選：與行事曆整合

## 重要提醒

- 法說會日期可能變動 — 接近日期時請透過公司 IR 頁面及 TWSEMCPServer 確認
- 注意提前預警風險：追蹤有提前公告習慣的公司（正面或負面）
- 研討會出席名單極具價值 — 哪些公司出席、哪些 conspicuously 缺席？
- 部分催化劑為例行性（每月營收公告）— 建立模板自動填入
- 按影響程度顏色標記：紅色 = 高影響、黃色 = 中等、綠色 = 例行
- 歸檔已發生的催化劑及實際結果 — 長期累積模式識別能力
