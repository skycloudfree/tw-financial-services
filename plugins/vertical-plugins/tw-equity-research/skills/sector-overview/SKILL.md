# 產業概覽 (Sector Overview)

## 工作流程

### 步驟 1：定義範圍

- **產業 / 次產業**: 何種行業？範圍多窄？
- **目的**: 客戶報告、內部研究、提案材料、想法產生
- **深度**: 高層級概覽（5-10 頁）或深入分析（20-30 頁）
- **角度**: 中立 landscape 或主題式論點（如「AI 基礎建設建置」）
- **範圍**: 僅上市公司，或包含未上市？

### 步驟 2：市場概覽

**市場規模與成長**
- 總可達市場 (TAM) 含資料來源
- 歷史成長率（5 年 CAGR）
- 預測成長率及關鍵假設
- 市場細分（按產品、地區、終端市場、客戶類型）

**產業結構**
- 分散 vs. 集中 — 前 5 大市佔率
- 價值鏈地圖 — 價值在哪裡累積？
- 商業模式類型（訂閱、交易、授權、服務）
- 進入障礙（資本、法規、技術、網路效應）

**關鍵趨勢與驅動因子**
- 結構性順風（3-5 個主要趨勢）
- 逆風與風險
- 技術顛覆方向
- 法規發展
- M&A 活動與整併趨勢

### 步驟 3：競爭 landscape

**公司簡介**（前 5-10 家）：

| 公司 | 營收 | 成長率 | EBITDA 利潤率 | 市佔率 | 關鍵差異化因子 |
|------|------|--------|--------------|--------|---------------|
| | | | | | |

每家公司簡介：
- 業務描述（2-3 句）
- 策略定位與護城河
- 近期發展（財報、M&A、產品上市）
- 估值 snapshot（P/E、EV/EBITDA、EV/Revenue）

**競爭動態**
- 公司如何競爭？（價格、產品、服務、通路）
- 誰在 gain/lose 佔有率及原因？
- 來自新進入者或相鄰產業的顛覆風險

### 步驟 4：估值背景

- 產業交易倍數（目前及歷史區間）
- 溢價/折價驅動因子（成長、利潤率、市場地位）
- 近期 M&A 交易倍數
- 該產業與大盤（台灣加權指數）的比較

### 步驟 5：投資啟示

- 最佳 risk/reward 機會在哪裡？
- 哪些主題性押注可透過此產業表達？
- 產業關鍵辯論（多方 vs. 空方論點）
- 可能改變產業敘事的催化劑

### 步驟 6：產出

- Word 文件或 PowerPoint：
  - 市場概覽與規模
  - 競爭 landscape 地圖
  - 公司比較表
  - 估值摘要
  - 關鍵圖表：市場成長、市佔趨勢、估值歷史
- Excel 附錄含詳細公司資料

## 重要提醒

- 所有市場規模資料須標註來源 — 引用研究機構或方法論
- 區分 TAM hype 與 realistic 可達市場
- 產業概覽快速過時 — 註明日期並標示可能已過時的資料
- 圖表至關重要 — 市場規模 waterfall、競爭定位矩陣、估值 scatter plot
- 若為客戶製作，針對其特定情境調整「so what」（M&A 目標識別、競爭定位、市場進入策略）
