# 模型更新 (Model Update)

## 工作流程

### 步驟 1：確認變更內容

判斷更新觸發原因：
- **季報公告**: 新季度實際值需帶入
- **財測變動**: 公司更新前瞻展望
- **預估修正**: 分析師根據新資料調整假設
- **總經更新**: 利率、匯率、原物料價格變動
- **事件驅動**: M&A、重組、新產品、經營層變動

### 步驟 2：帶入新資料

#### 財報後
以實際公告值更新模型：

| 損益項目 | 原預估 | 實際值 | 差異 | 備註 |
|----------|--------|--------|------|------|
| 營收 | | | | |
| 毛利率 | | | | |
| 營業費用 | | | | |
| EBITDA | | | | |
| EPS | | | | |
| [關鍵指標 1] | | | | |
| [關鍵指標 2] | | | | |

**部門細節**（如適用）：
- 更新各部門營收與利潤率
- 記錄部門組合變化

**資產負債表 / 現金流量表更新**：
- 現金與負債餘額
- 股數（庫藏股、稀釋）
- 資本支出實際 vs. 預估
- 營運資金變動

### 步驟 3：修正前瞻預估

根據新資料調整前瞻預估：

| | 原 FY 預估 | 新 FY 預估 | 變動 | 原明年預估 | 新明年預估 | 變動 |
|---|-----------|-----------|------|-----------|-----------|------|
| 營收 | | | | | | |
| EBITDA | | | | | | |
| EPS | | | | | | |

**關鍵假設變動：**
- 變更哪些假設及原因？
- 營收成長率：原 → 新（理由）
- 利潤率假設：原 → 新（理由）
- 新增項目（重組費用、一次性收益等）

### 步驟 4：評價影響

以更新後預估重新計算評價：

| 評價方法 | 原值 | 更新值 | 變動 |
|---------|------|--------|------|
| DCF 公允價值 | | | |
| P/E (NTM EPS × 目標倍數) | | | |
| EV/EBITDA (NTM EBITDA × 目標倍數) | | | |
| **目標價** | | | |

### 步驟 5：摘要與行動

**預估變動摘要：**
- 一段落：什麼變了、為何變、對股價的意義
- 這是 thesis-changing 事件還是雜訊？

**評級 / 目標價：**
- 維持或變更評級？
- 新目標價（如變動）及方法論
- 相對於現價的 upside/downside

### 步驟 6：產出

- 更新後 Excel 模型（若使用者提供現有模型）
- 預估變動摘要（markdown 或 Word）
- 更新後的目標價推導

## 重要提醒

- 在進行前瞻預測前，務必將你的預估與公司公告數據 reconcile
- 註記一次性項目，並說明你的預估是 IFRS 還是調整後數字
- 追蹤預估修正歷史 — 反映分析能力演進
- 若季度雜音較多，在預估變動中分離信號與雜訊
- 更新後檢查市場共識 — 你的修正後預估與市場比較如何？
- 股數影響重大 — 員工認股權、可轉債、庫藏股會顯著影響 EPS
