# 法說會前預覽 (Earnings Preview)

## 工作流程

### 步驟 1：收集背景資訊

- 確認公司及報告季度
- 透過 TWSEMCPServer 拉取市場共識預估（營收、EPS、關鍵部門指標）
- 查詢法說會日期與時段（盤後 vs. 盤前）
- 回顧公司上一季法說會內容，查看是否有財測或 commentary

### 步驟 2：關鍵指標框架

建立專屬的「觀察指標」框架：

**財務指標：**
- 營收 vs. 市場共識（總額及按部門）
- EPS vs. 市場共識
- 利潤率（毛利率、營業利益率、淨利率）— 擴張或收縮？
- 自由現金流
- 前瞻財測 vs. 市場共識

**營運指標**（依產業別）：
- 科技/SaaS: ARR、淨留存率、RPO、客戶數
- 零售: 同店銷售、來客數、客單價
- 製造業: 在手訂單、B/B 值、價格 vs. 數量
- 金融: 淨利差、資產品質、放款成長、手續費收入
- 生技: 處方量、就診人數、產品線進度

### 步驟 3：情境分析

建立 3 種情境及股價影響評估：

| 情境 | 營收 | EPS | 關鍵驅動因子 | 股價反應 |
|------|------|-----|-------------|----------|
| 樂觀 | | | | |
| 基準 | | | | |
| 悲觀 | | | | |

每種情境需說明：
- 營運面上需發生什麼事
- 管理層何種評論會暗示此情境
- 歷史經驗 — 類似財報表現時股價如何反應？

### 步驟 4：催化劑檢查清單

辨識 3-5 個決定股價反應的關鍵因素：

1. [指標] vs. [市場共識/耳語數字] — 為何重要
2. [財測項目] — 買方預期聽到什麼
3. [敘事轉變] — 任何策略變化、M&A、重組

### 步驟 5：產出

一頁法說會前預覽：
- 公司、季度、法說會日期
- 市場共識預估表
- 關鍵觀察指標（按重要性排序）
- 樂觀/基準/悲觀情境表
- 催化劑檢查清單
- 交易設定：近期股價表現、選擇權隱含波動

## 重要提醒

- 市場共識會變動 — 務必註明預估來源及日期
- 買方調查的「耳語數字」通常比 published 共識更具參考價值
- 歷史法說會反應可協助校準預期（搜尋「[公司代號] 法說會反應」）
- 選擇權隱含波動告訴你市場的預期 — 與你的情境比較
