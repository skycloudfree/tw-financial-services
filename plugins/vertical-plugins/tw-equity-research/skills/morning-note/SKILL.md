# 晨間簡報 (Morning Note)

## 工作流程

### 步驟 1：隔夜發展

掃描涵蓋範圍內相關事件：

**財報與財測**
- 任何涵蓋公司於盤後或盤前公告？
- 財報驚喜（營收、EPS、關鍵指標優於/低於預期）
- 財測變動（上調、下調、維持）

**新聞與事件**
- M&A 公告或傳聞
- 經營團隊異動
- 產品上市或法規決議
- 同業分析師升/降評
- 影響該產業的總經數據或政策變動

**市場背景**
- 隔夜台指期 / 盤前動向
- 產業 ETF 表現
- 相關原物料或匯率變動
- 今日關鍵經濟數據發布

### 步驟 2：晨間簡報格式

保持精簡 — 應在 2 分鐘內讀完：

---

**[日期] 晨間簡報 — [分析師名稱]**
**[涵蓋產業]**

**重點提示: [標題 — PM 需聽到的一件事]**
- 2-3 句說明關鍵發展及為何重要
- 對股價影響：目標價、評級重申/變更

**隔夜/盤前發展**
- [公司 A]: 一行摘要財報/新聞 + 我們看法
- [公司 B]: 一行摘要 + 我們看法
- [產業/總經]: 相關產業整體發展

**今日關鍵事件**
- [時間]: [公司] 法說會
- [時間]: 經濟數據發布（預期 vs. 我們看法）
- [時間]: 研討會或法人說明會

**交易想法**（如有）
- [做多/做空] [公司]: 1-2 句論點 + 催化劑
- 風險：何種情況會使此想法錯誤

---

### 步驟 3：財報快評

若涵蓋公司已公告，提供快速反應：

| 指標 | 市場共識 | 實際值 | 優於/低於 |
|------|---------|--------|-----------|
| 營收 | | | |
| EPS | | | |
| [關鍵指標] | | | |
| 財測 | | | |

**我們看法**：2-3 句 — 對股價正面或負面？是否改變論點？

**行動**：維持 / 升級 / 降級評級？調整目標價？

### 步驟 4：產出

- Markdown 文本（email/Slack 發送）
- Word 文件（如需正式發送）
- 限 1 頁 — PM 與交易員不會讀更多

## 重要提醒

- 要有觀點 — 僅摘要新聞而無看法的晨間簡報毫無價值
- 以最重要的事情開頭 — 不要埋沒標題
- 「無新聞」也是有效的晨間簡報 — 表示「隔夜無重大事件，維持當前持倉」
- 區分可行動事件（財報、M&A）與雜訊（小型分析師報告、非事件）
- 為你的看法標註時間 — 若在 6am 撰寫，需註明盤前可能隨開盤改變
- 若判斷錯誤，在隔天晨間簡報勇於承認 — 可信度比每次都對更重要
