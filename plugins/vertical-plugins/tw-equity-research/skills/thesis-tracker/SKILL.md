# 論點追蹤器 (Thesis Tracker)

## 工作流程

### 步驟 1：定義或載入論點

若建立新論點：
- **公司**: 名稱與代號
- **方向**: 做多或做空
- **論點陳述**: 1-2 句核心論點（如「做多 ACME — 定價能力帶動利潤率擴張 + 產品組合轉向軟體的營運槓桿」）
- **關鍵支柱**: 3-5 個支持論證
- **關鍵風險**: 3-5 個可能 invalidate 論點的風險
- **催化劑**: 可 prove/disprove 論點的 upcoming 事件（財報、產品上市、法規決策）
- **目標價 / 估值**: 若論點實現，值多少
- **停損觸發**: 何種情況需出場

若更新既有論點，詢問使用者新數據點或發展。

### 步驟 2：更新紀錄

針對每個新數據點或發展：

- **日期**: 發生時間
- **數據點**: 什麼變了（財報優於預期、經營層離職、競爭對手動作等）
- **論點影響**: 此事件加強、削弱或中性影響哪個支柱？
- **行動**: 不變 / 加碼 / 減碼 / 出場
- **更新信心**: 高 / 中 / 低

### 步驟 3：論點計分卡

維護持續更新的計分卡：

| 支柱 | 原始預期 | 目前狀態 | 趨勢 |
|------|---------|---------|------|
| 營收成長 >20% | 符合預期 | Q3 為 22% | 穩定 |
| 利潤率擴張 | 落後 | 利潤率持平 YoY | 需關注 |
| 新產品上市 | 待確認 | 延至 Q2 | 觀察 |

### 步驟 4：催化劑日曆

追蹤 upcoming 催化劑：

| 日期 | 事件 | 預期影響 | 備註 |
|------|------|---------|------|
| | | | |

### 步驟 5：產出

適合以下用途的論點摘要：
- 晨會討論
- 投資組合檢視
- 風控委員會簡報

格式：簡潔 markdown 或 Word 文件，含計分卡、近期更新與當前信心程度。

## 重要提醒

- 論點應可被 falsify — 若沒有任何事能否定它，那就不是論點
- 追蹤反面證據應與正面證據同樣 rigorous
- 至少每季檢視論點，即使沒有重大事件發生
- 若使用者管理多個部位，可主動提議進行完整投資組合論點檢視
- 以結構化格式儲存論點資料，以便跨 sessions 參考
