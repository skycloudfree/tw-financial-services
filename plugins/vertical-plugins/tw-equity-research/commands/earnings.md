# Earnings Analysis Command

建立專業的 equity research 季報盈餘更新報告。

## Workflow

### Step 1: 收集資訊

解析輸入：
- 公司名稱或股票代號
- 季度（如 2024 Q3、FY25 Q2）

若未提供，詢問：
- "您要分析哪家公司的季報？"
- "哪個季度？（如 2024 Q3）"

### Step 2: 確認時效性

**關鍵**：開始前確認資料為最新：
1. 搜尋「[公司名稱] 最新季報 [今年]」
2. 確認營收/財報公告在近 3 個月內
3. 確認法說會日期與財報日期一致

若資料過時，告知使用者並搜尋最新資料。

### Step 3: 載入 Earnings Analysis Skill

使用 `skill: "earnings-analysis"` 建立報告：

1. **資料收集**（搜尋最新資料）：
   - 營收公告/財報新聞稿
   - 公開資訊觀測站 (MOPS) IFRS 財務報告
   - 法說會逐字稿
   - 投資人簡報/補充資料
   - 市場共識預估（TWSEMCPServer）

2. **優於/低於預期分析**：
   - 營收 vs 市場共識：優於/低於 XX 元或 X%
   - EPS vs 市場共識：優於/低於 XX 元或 X%
   - 各部門表現 vs 預期
   - 說明 WHY 結果有差異

3. **關鍵指標分析**：
   - 營收按部門/地區 breakdown
   - 利潤率趨勢（毛利率、營業利益率、淨利率）
   - 財測：上調/維持/下調
   - 更新前瞻預估

4. **生成圖表**（8-12 張）：
   - 季度營收趨勢
   - 季度 EPS 趨勢
   - 利潤率趨勢
   - 部門營收 breakdown
   - 優於/低於預期 summary
   - 預估修正
   - 評價圖表

5. **建立報告**（8-12 頁）：
   - 第 1 頁：摘要含評級與目標價
   - 第 2-3 頁：詳細結果分析
   - 第 4-5 頁：關鍵指標與財測
   - 第 6-7 頁：更新投資論點
   - 第 8-10 頁：評價與預估
   - 資料來源段落含可點擊超連結

### Step 4: 交付產出

提供：
1. **DOCX 報告** - 8-12 頁盈餘更新
2. **摘要** 重點說明：
   - 關鍵指標優於/低於預期
   - 財測變動
   - 論點影響（正面/中性/負面）

## Report Structure Reference

```
PAGE 1: EARNINGS SUMMARY
┌─────────────────────────────────────────────────────────────────┐
│ [公司] 2024 Q3 盈餘更新                                           │
│ 評級：BUY | 目標價：NT$XXX（由 NT$XXX）                           │
├─────────────────────────────────────────────────────────────────┤
│ 關鍵結論                                                         │
│ • 營收因 [部門] 表現強勁優於預期 X%                              │
│ • EPS 因利潤率擴張優於預期 NT$X.XX                               │
│ • FY 財測上調至 NT$X.XX-NT$X.XX（原 NT$X.XX-NT$X.XX）           │
│ • 論點不變；維持 BUY 評級                                        │
├─────────────────────────────────────────────────────────────────┤
│ 結果一覽                                                         │
│ ┌─────────────┬──────────┬──────────┬──────────┐               │
│ │ 指標        │ 實際值   │ 市場共識 │ 優於/低於│               │
│ │ 營收        │ NT$XB    │ NT$XB    │ +X.X%    │               │
│ │ EPS         │ NT$X.XX  │ NT$X.XX  │ +NT$X.XX │               │
│ │ 毛利率      │ XX.X%    │ XX.X%    │ +XXbps   │               │
│ └─────────────┴──────────┴──────────┴──────────┘               │
└─────────────────────────────────────────────────────────────────┘

PAGES 2-3: 詳細結果
- 各部門分析
- 地區別 breakdown
- 優於/低於預期主因

PAGES 4-5: 指標與財測
- 利潤率分析
- 全年財測比較
- 更新季度預估

PAGES 6-7: 論點更新
- 變動內容
- 風險與催化劑
- 投資建議

PAGES 8-10: 評價
- 更新 DCF/同業比較（如重大變動）
- 目標價說明
- 情境分析

SOURCES SECTION (含可點擊超連結):
- 營收公告：[hyperlink]
- 公開資訊觀測站 IFRS 財報：[MOPS hyperlink]
- 法說會逐字稿：[hyperlink]
- 市場共識：TWSEMCPServer as of [date]
```

## Quality Checklist

交付前確認：
- [ ] 財報資料為最新季度（非過時）
- [ ] 優於/低於預期已量化具體數字
- [ ] 所有圖表已嵌入（8-12 張）
- [ ] 資料來源段落含可點擊超連結
- [ ] 每張圖表皆有來源引用
- [ ] 財測變動清楚記載
- [ ] 評級與目標價於首頁明確標示
- [ ] 8-12 頁，3,000-5,000 字
